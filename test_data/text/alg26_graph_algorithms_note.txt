Core facts:

1. BFS and DFS both run in Theta(V + E).
2. Dijkstra solves single-source shortest paths with non-negative edge weights.
3. Bellman-Ford allows negative edges and can detect negative cycles.
4. Floyd-Warshall solves all-pairs shortest paths in Theta(V^3).
5. Edmonds-Karp solves max flow in O(VE^2).
6. Dinic solves max flow in O(V^2E) on general graphs.
